# 8W0907559H__0008

**ECU:** Bosch MDG1 (MG1CS002IFX)
**Vehicle:** Audi (B9/C8 platform)
**Endianness:** Big-endian

---

## Write Parameters

| Parameter | Value |
|-----------|-------|
| mid_byte | `0x09` |
| address_offset | `0x040000` (256 KB offset applied to all writes) |
| Max chunk size | 64 bytes |

Write frame: `3E 39 01 09 [addr_2] [addr_1] [addr_0] [data...]`

**Note:** Every target address has `0x40000` subtracted before transmission.
Example: writing to `0x6A8550` → wire address = `0x6A8550 − 0x40000` = `0x668550`.

## Special Addresses

| Purpose | Address | Description |
|---------|---------|-------------|
| Ethanol memory | `0x6A8550` | Write current ethanol % for flex fuel blending |
| Speed display | `0x651F30` | Speed limiter / display override |

### Value Conversion

```
physical = (raw_uint16_BE × scale) + offset
```

All multi-byte values are **big-endian** in ECU RAM (byte at lower address is MSB).

### Unique Variables

This is the only boxcode with:
- `gang` — current gear position
- `frm` / `frm2` — per-bank short term fuel trims
- `lambts` / `lambts2` — per-bank lambda sensor readings
