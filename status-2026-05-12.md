## Three-layer HIL preflight validation gate (Layer 1/2/3 all PASS)

**Scope:** before any further work toward P-07 (real-bench Phase 2 flash on dev RS7), build a three-layer regression gate proving the orchestrator's HIL halt-before-erase path is correct in host + dongle, and produces byte-identical output across both. This was the gap surfaced in `docs/HIL_PREFLIGHT_RS7_CAL_FLASH_READINESS.md` — the original preflight doc skipped these.

**Outcome: all three layers GREEN.**

### Layer 1 — host unit test for the HIL halt gate
- Added `MDG1_HIL_PREFLIGHT_HALT_BEFORE_ERASE` compile-time flag (default 0) + runtime `mdg1_flash_plan_t::hil_halt_before_erase` field. Either path triggers an `ESP_ERR_NOT_FINISHED` return between fingerprint-ack and the per-section erase loop.
- Added `MDG1_FLASH_PHASE_HIL_HALT_BEFORE_ERASE` enum value (appended, no renumbering).
- Added scenario `test_hil_preflight_halt_before_erase_no_erase_emitted` to `firmware/test/mdg1_flash_orchestrator/test_orchestrator.c`. Asserts: return rc == ESP_ERR_NOT_FINISHED; shadow log contains `2EF15A` (fingerprint write) and `6EF15A` (fingerprint ack); shadow log contains NO `3101FF00` (erase routine); halt progress event fires exactly once.
- Updated `eval.sh` REQUIRED_SCENARIOS list (count = 14, was 13).
- `eval.sh`: PASS 64 / FAIL 0. host_test_runner: 42 asserts PASS / 0 FAIL across 14 scenarios.

### Layer 2 — dongle shadow dry-run via NVS autostart
- Surfaced blocker: dongle's `sdkconfig` has `CONFIG_ESP_CONSOLE_UART_DEFAULT=y` primary + USJ secondary-output, so USB-CDC stdin doesn't reach `serial_console_task`. Filed as **P-16** in `docs/PHASE_2_PREREQUISITES.md` for follow-up.
- Built around it with NVS-armed autostart:
    - New module `firmware/src/flash/phase2_hil_autostart.{c,h}`. `arm()` writes `phase2/hil_pf_armed=1`. `run_if_armed()` reads + CLEARS first (one-shot, crash-safe), then runs the orchestrator shadow preflight + dumps the log over UART as base64 between `[PHASE2_HIL_AUTOSTART_LOG_BEGIN/END]` markers.
    - New WS/serial command `phase2_hil_preflight_arm` in `commands/phase2_hil_preflight_commands.{c,h}` + registry + serial console.
    - main.c wires `phase2_hil_autostart_run_if_armed()` between Phase 2 AES iface init and "System initialized".
- Found + fixed a real stack-overflow bug in `mdg1_transport_shadow.c`: five `hex_buf[MDG1_MAX_UDS_MESSAGE_BYTES*2+4]` (8204-byte) stack allocations on the main_task. Replaced with heap (`hex_alloc_and_canon`). Boot loop reproduced before the fix, dongle stable after.
- Phase A dry-run validated: arm → read → clear → marker; second boot shows no marker (one-shot proven).
- Phase B end-to-end validated: rc=268 (ESP_ERR_NOT_FINISHED), halt=1, erase=0, events=4, base64 dump emitted between markers.
